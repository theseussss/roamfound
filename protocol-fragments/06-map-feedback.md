   2.6.8. 地图感反馈（复杂 / 多轮任务）
   
   多轮复杂任务中，AI 须主动输出"我们在哪"，避免闷头干偏题不自知；这里的“在哪”分两层：**短面包屑每轮首段固定输出**，完整地图感按下方触发节奏输出。完整地图感不是普通进度摘要，而是把当前焦点、话题结构位置、讨论状态与历史事件合成一张地图。

   **短面包屑固定格式（每轮首段必有）**：
   ```text
   当前位置：父话题 > 当前话题:TNN
   层级判断：独立 / 下属 / 支线 / 关联
   本轮归位：scratch / card / tasks / logs / doc / 无写入
   ```
   - `当前位置`：每轮必有；skill 激活时来自 `.jiacong/focus.json` + `focus_breadcrumb.py`（旧 `.claude/focus` 仅作 fallback）
   - `层级判断`：新话题、切焦点、话题归位时必有；普通延续轮可写“延续当前焦点”
   - `本轮归位`：有写入、决策、沉淀或执行动作时必有；纯回答可写“无写入”
   注意：`logs` 只用于话题开启、切换、关闭这些生命周期节点；普通延续轮归位 `scratch`，不写 `logs/stream.md`。

   **两种地图视角**（/jiacong-flow:smarter-project skill 激活时具体化；否则抽象描述）：
   
   - **线性地图**：当前焦点面包屑（`.jiacong/focus.json` + `focus_breadcrumb.py`），回答“当前正在处理哪张话题卡 / 哪个任务分支”
   - **话题流转地图**：讨论流转（scratch 💭/🌱/📦）+ 结构位置（`_tree.md` 父子/根话题）的合一视图；包含历史事件（`logs/stream.md`），回答“这件事从哪里来、卡在哪、下一步应进入 scratch/card/tasks/doc 的哪一层”
   
   **反馈内容**：
   - 当前位置（焦点话题 + 讨论状态 + 在 `_tree.md` 中的父子/根话题位置）
   - 已完成 / 在做 / 待做
   - 可选分支（推进 / 回头 / 切焦点）
   - 偏离迹象（与原计划不符的苗头）
   
   **默认姿态**：开放心态（保留分支，不锁死路径）+ 系统思维（看森林，不只看当前话题）。
   
   **触发节奏**（不是每轮都喊）：
   - 每完成一个关键节点后
   - 遇到分叉决策前
   - 用户沉默 / 反应异常时
   - 已讨论 ≥5 轮但未给"在哪"感
   
   不启用 skill 时退化为抽象层："我们在 X 阶段，刚完成 Y，下一步是 Z"。
